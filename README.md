### Featured projects

**[ProStaff](https://github.com/nishit3/ProStaff)** — Enterprise HR Management System built with 14+ microservices using Spring Cloud (Eureka, API Gateway). Covers employee management, payroll, and attendance with JWT-based auth and RBAC. Razorpay integration for salary disbursement on a database-per-service pattern.

**[EarthAlly](https://github.com/nishit3/EarthAlly)** — IoT environmental monitoring platform. Serverless pipeline on AWS (Lambda, S3, DynamoDB) processing 50k+ daily sensor readings. PyTorch models trained on 50k+ data points and deployed on SageMaker. Flutter app for real-time dashboards.

**[Neuronify](https://github.com/nishit3/Neuronify)** — No-code platform for training neural networks through a visual workflow builder. Backend handles model persistence, checkpointing, and export to deployment-ready code.

A few more worth a look: **[Kisan-Sevak](https://github.com/nishit3/Kisan-Sevak)** (DL + IoT farming assistant), **[SmartFit](https://github.com/nishit3/SmartFit)** (IoT posture monitor), **[GAN-Models](https://github.com/nishit3/GAN-Models)**.
